## Решения командира

| Когда | Что решено | На основании |
|-------|------------|--------------|
| 2026-09-21 | Дешёвый вариант: пиксельные дельты, игнор инерции, настраиваемый модификатор; жест 4 пальцами и панорамирование — вне скоупа | выбор пользователя |
| 2026-09-21 | Порог шага оставлен `W / min(колонок, 3)` (960 pt у пользователя = `W / visible_columns`); подстройка — `scroll_sensitivity` после живой проверки | вопрос T1; у пользователя обе формулы совпадают |
| 2026-09-21 | Принят ручной `#[default] Alt` у `ScrollModifier` | нужен только для чтения старых трасс; пользовательское значение из glide.default.toml |
| 2026-09-21 | Волна 1 не закрыта: R1-test красный. F1 = R1-test 1,2,3,5 + R1-qa 1 (фиксированный порог ~250 pt × 20/sensitivity) + R1-qa 3 | правило красного вердикта; R1-qa 1 — основная пользовательская проблема |
| 2026-09-21 | Проверка: R1-test + R1-qa, без -sec и -arch | нет нового внешнего ввода и новых границ модулей |
