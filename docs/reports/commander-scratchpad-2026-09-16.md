## Что получилось

Команда `toggle_scratchpad` и правило окна `scratchpad` — аналог scratchpad из yabai. Хоткей (например ⌘⌥K) показывает приложение (Keyguard) поверх текущего рабочего стола в заданной рамке и с фокусом, повторное нажатие прячет его (скрытие приложения, как Cmd+H). Если приложение не запущено — запускает его (`open -b`) и показывает окно, когда оно появится (не позже 30 с). Окно с другого рабочего стола переносится на текущий через приватный SkyLight (`SLSBridgedMoveWindowsToManagedSpaceOperation`) — без scripting addition и без изменений SIP.

Использование — `README.md` (раздел «Scratchpad windows») и комментарии в `glide.default.toml`.

## Ключевые решения по ходу

| Решение | Почему |
|---------|--------|
| Прятать — скрытием приложения; геометрия — доли экрана; перенос на текущий стол — да; только форк | выбор пользователя |
| Исполнители работают в отдельных git worktree | параллельная работа в одной копии ломает ветки |
| Форматирование — прямой вызов nightly `rustfmt` | `cargo fmt` на этой машине подхватывает stable и переформатирует весь репозиторий |
| Проверки волн 1–2 урезаны | волны без пользовательского поведения |
| Контракт 5.2 расширен (`PendingShowId`, срок жизни показа) | защита от кражи фокуса окном менеджера паролей; параллельных потребителей контракта не было |
| Время для сроков — записываемыми событиями, не часами | детерминированный record/replay |
| Дубли имён scratchpad — ошибка конфига | одно приложение на имя |
| Явное скрытие пользователем отменяет ожидание переноса | воля пользователя важнее таймаута |
| Окно, которое Glide ни разу не видел, не переносится — описано в документации | минимальный риск до живой проверки |
