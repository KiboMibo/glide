## Что сделано

| Находка | Как закрыта | Тест |
|---|---|---|
| R1-sec S1 (важная): `move_window_to_space` не проверяет методы | Новая `verify_move_operation(cls)` проверяет `initWithWindows:spaceID:` как `(&NSArray, u64) -> *mut AnyObject` (кодировки `@ @ Q` → `@`) и `performWithWMBridgeDelegate` как `() -> ()` через `AnyClass::verify_sel`. Класс вместе с результатом проверки кешируется в `OnceLock<Option<&AnyClass>>`, при ошибке функция возвращает `SpaceMoveError::Unsupported` ещё до `alloc`. | `verification_fails_for_a_class_without_the_methods` (NSObject → Err, без паники); `verification_accepts_the_skylight_class_when_present` (на текущем macOS класс проходит проверку, окна не двигаются) |
| R1-test #1 (важная): у `ReactorCommand` нет `deny_unknown_fields` | На enum добавлен `#[serde(deny_unknown_fields)]`. В serde 1.0.228 атрибут действует на struct-варианты. Опечатка отвергается и через untagged `Command`/`WmCommand`. | `config::tests::toggle_scratchpad_with_unknown_field_is_rejected`. Без атрибута тест падает (проверено). Существующие `toggle_scratchpad_command_parses` и `default_keys*` проходят. |
| R1-test #2 (замечание): имя scratchpad из пробелов | В `WindowRule::validated` пустота проверяется после `trim()` | `config::tests::blank_scratchpad_name_is_rejected` |

- Составные команды оболочки с `git` (через `&&` и heredoc) хук изоляции worktree отклоняет. Команды `git` нужно запускать по отдельности.
